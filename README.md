# pretec

Параметрические 3D-модели нутационной (прецессирующей) передачи с двухвенцовым сателлитом.

## Структура

```
pretec/
├── models/z1_z2/     # пара Z1/Z2: STL, summary.json, kompas_*.json
├── scripts/
│   ├── nutation_gears.py   # генератор (нужен только numpy)
│   └── kompas_build.py     # построение в КОМПАС-3D v21 (pywin32)
├── README.md
└── .gitignore
```

## Исходные данные

| Параметр | Значение |
|---|---|
| Числа зубьев Z1, Z2, Z3, Z4 | 15, 16, 18, 17 |
| Передаточное число | i = 1 / (1 − Z1·Z3 / (Z2·Z4)) = 136 |
| Угол нутации θ | 10,511009° |

Для пары 3-4 полуугол делительного конуса венца сателлита получается ровно 78,0000°, то есть θ согласован с этим условием.

## Запуск

```
python3 scripts/nutation_gears.py --pair 12 --out models/z1_z2
```

Параметры (по умолчанию): `--module 2.0`, `--alpha 20`, `--ha 1.0`, `--hf 1.25`, `--width 0.333`, `--theta 10.511009`. Пара 3-4: `--pair 34`.

## Модель зацепления

- Оси колеса и сателлита пересекаются в точке O под углом θ. Делительные конусы пары имеют общую вершину и касаются по образующей.
- Колёса Z1 и Z4 имеют наружные зубья, венцы сателлита Z2 и Z3 — внутренние (Z сателлита больше Z колеса).
- Зубья прямые, профиль — сферическая эвольвента. Боковая поверхность зуба — конус с вершиной O.
- Модуль задан на внешнем торце; торцы — сферы радиусов R_in и R_out.

## Пара Z1/Z2 (m = 2 мм, α = 20°)

| Величина | Колесо Z1 | Венец Z2 |
|---|---|---|
| Полуугол делительного конуса | 65,4191° | 75,9301° |
| Полуугол основного конуса | 58,708° | 65,714° |
| Делительный диаметр на внешнем торце | 30 мм | 32 мм |

Внешнее конусное расстояние R = 16,495 мм, ширина венца 5,498 мм.

## Проверки

- Обе сетки замкнутые, вырожденных треугольников нет.
- Взаимное проникновение профилей при вращении пары (с нулевым боковым зазором): около 1 мкм, на уровне дискретизации. Контрольный сдвиг фазы на 5 мкм даёт десятки мкм, то есть проверка чувствительна.

## Скрипт для КОМПАС-3D v21

`scripts/kompas_build.py` строит венец как нативную деталь с деревом построения. Данные берёт из `models/z1_z2/kompas_z1_wheel.json` и `kompas_z2_crown.json`, которые создаёт `nutation_gears.py`.

**Статус: не запускался на реальном КОМПАС.** Проверена только логика Python на заглушках (число отрезков и дуг в эскизах, порядок операций). Вызовы API (плоскость под углом, вырез по сечениям, круговой массив) могут потребовать правки.

Нужно: Windows, 64-разрядный Python, `pip install pywin32`.

```
python scripts/kompas_build.py --diag
python scripts/kompas_build.py models/z1_z2/kompas_z1_wheel.json --stage blank
python scripts/kompas_build.py models/z1_z2/kompas_z1_wheel.json --stage gap
python scripts/kompas_build.py models/z1_z2/kompas_z1_wheel.json --stage full --save z1_wheel.m3d
```

Этапы: `blank` (заготовка вращением), `gap` (плюс вырез одной впадины), `full` (плюс круговой массив). Ключи ориентации, если модель получилась зеркальной или плоскости наклонились не туда: `--tilt-sign -1`, `--flip-x`, `--flip-z`. Если вырез оказался выше заготовки (начало эскиза на наклонной плоскости стоит не в проекции начала координат, а на пересечении плоскости с осью Z): `--origin axis`. Скрипт на этапе выреза печатает, где должен быть центр каждого сечения, для сверки с КОМПАС.

Метод: боковые стороны зуба — конусы с вершиной O. Впадина вырезается по сечениям между двумя плоскостями, перпендикулярными образующей делительного конуса (все рёбра проходят через O). Сечения плоскостью, перпендикулярной оси, для венца Z2 не годятся: его конус 75,9°, дно впадин почти плоское.

## Упрощения (первая версия)

- Нулевое смещение исходного контура, нулевой боковой зазор.
- Переходная кривая у основания зуба заменена простым скруглением.
- Торцы венцов сферические. Ступица колеса (отверстие) и обод венца заданы условно.
- Пара 3-4 пока не построена (строится тем же скриптом, `--pair 34`).
