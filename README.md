# pretec

Параметрические 3D-модели и скрипты для их генерации.

## Структура

```
pretec/
├── models/    # готовые модели (STEP, STL, 3MF)
├── scripts/   # скрипты генерации (CadQuery, build123d, OpenSCAD, Python)
├── README.md
└── .gitignore
```

## Как пользоваться

1. Скрипты из `scripts/` строят модели по параметрам, заданным в начале каждого файла.
2. Результат экспорта сохраняется в `models/`.
3. Каждая модель описывается в этом файле: назначение, параметры, формат экспорта.
